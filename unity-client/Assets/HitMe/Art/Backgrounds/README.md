# Main Menu environment production brief

The current menu reuses the independent LangQueBacBo arena backdrop as a controlled fallback.
The approved full-screen concept is reference only; it is not an interactive UI texture.

Produce separate portrait PNG layers for village gate/far sky, architecture/tree midground,
and foreground stall/props with a quiet central character stage. Export transparent layers
where appropriate, 2–3 tone stylized Vietnamese cartoon shading, matching the existing characters.
Avoid baking logo, player data, cards or navigation into background pixels.
Target a 390×844 composition with enough overscan for 360×800 through 430×932.
