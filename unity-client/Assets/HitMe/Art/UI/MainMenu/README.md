# Sprint 5 UI pipeline

Buttons and icons are original code-native PNG assets, generated by tools/menu-assets.py.
MainMenuPngImporter configures Sprite/100 PPU/no mipmaps/clamped/bilinear/uncompressed alpha.
Buttons have 32 px borders and are rendered using Image.Type.Sliced; icons preserve aspect.
MainMenu.spriteatlas packs frames, icons, logo and shadow with rotation disabled and 4 px padding.
Logo is an independent PNG using the existing OFL HitMe Nunito font.

Still required for final visual-art acceptance: hand-painted village gate background layers,
dedicated portrait PNGs, illustrated map/character/collection/ranking cards, and polished
material textures/frame art. Current line icons and frame art are controlled fallbacks.
